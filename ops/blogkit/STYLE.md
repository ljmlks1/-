# 1번 계정(ljmlks1) 글쓰기 스타일 가이드

근거: 2026-11-14 네이버 블로그 검색 상위 노출 글 6개 구조 분석 + 대표님 기존 글(군포 신혼부부 대출이자) 스타일.
문장·이미지는 절대 복사하지 않는다. 구조와 패턴만 따른다. (네이버 유사문서 필터 → 누락/저품질 위험)

## 1. 제목 공식 (어그로+후킹이 1순위, 30~45자)
**클릭하고 싶게 만드는 게 제일 중요하다.** "심각해서 들어오거나" "재밌어서 들어오거나" 둘 중 하나.
구조: `[훅(감정)] + [핵심 키워드] + [숫자] + [행동 약속]`

훅 패턴 (매번 다르게 섞어 쓴다):
- 경고형: `큰일났다?`, `또 터졌다?`, `비상!`, `지금 당장 확인하세요`, `이거 모르면 손해`
- 반문형: `~했다고?`, `이게 실화?`, `우리는 얼마?`, `나도 해당될까?`
- 손해 회피형: `세금 폭탄 맞기 전에`, `돈 날리기 전에`, `마감 3일 남았다`
- 숫자 약속형: `5가지 총정리`, `딱 3분 정리`, `한 장으로 정리`

예시:
- `노란우산 개인정보 유출 또 터졌다? 문자 받았다면 지금 당장 해야 할 5가지 총정리`
- `엔비디아 폭락에 4,281억 줍줍했다고? 이거 모르면 내년 5월 세금 폭탄`
- `이재용 증여세가 1조6천억?! 부모님 집 물려받으면 우리는 얼마 낼까`
- `신혼부부 300만원 공짜 이자, 아직도 모르세요? 마감 D-3 신청방법`

지켜야 할 선:
- 자극적이어도 **사실과 다른 내용은 쓰지 않는다.** 확실하지 않으면 물음표로 쓴다(`큰일났다?`).
- 핵심 키워드는 제목 앞쪽 15자 안에 넣는다(검색 노출).
- 특정 인물을 비하하거나 범죄를 단정하지 않는다. 재난·사망 사건을 웃음 소재로 쓰지 않는다.

## 2. 본문 구조 (2,500~3,500자, 이미지 5~7장)
1. **대표 썸네일** (thumb.js 생성 1080×1080, 실사 사진 + 훅 문구)
2. **인용구 훅** 2줄: 결론 숫자 + 마감일 (예: “신혼부부라면 최대 300만원. 이번 주 금요일이 마감입니다.”)
3. **도입 3~4줄**: 독자 상황 공감 → 오늘 정리할 3가지 예고. 첫 3줄 안에 금액·날짜·대상이 다 나온다.
4. **본문 사진** (주제 관련, 대표님이 직접 넣을 위치 표시 `[사진: 설명]`)
5. **소제목 인용구 박스 4~6개**, 순서 고정:
   - 핵심 요약(누가/얼마/언제까지) → 지원 대상·조건 → 지원 내용(표) → 필요서류(표) → 신청방법(단계) → 주의할 점/FAQ
6. **표 1~2개**: 구분/내용 2열. 헤더 배경 연한 주황(#FDE7D3).
7. **CTA 버튼 1~2개** (초록=정부24/온라인 신청, 파랑=공식 공고문): `[버튼: 문구 → URL]`로 표시, 링크 붙여 이미지 삽입.
8. **문의처** (기관명 + 전화번호 굵게, 연두 하이라이트)
9. **기준일·면책 1줄**: “2026년 11월 15일 기준, 예산 소진 시 조기 마감될 수 있어 공고문을 꼭 확인하세요.”
10. **해시태그 8~12개**: 지역+대상+지원명 조합 롱테일.

## 2-1. 서식 고정값 (대표님 확정)
- 글자 색: 전부 **검은색**(#000000). 형광 강조(배경색)만 허용.
- 글꼴: 전부 **마루부리**. 기본 크기 **16**.
- 소제목: 네이버 인용구 **포스트잇**, **19 굵게**. 도입부 훅: 인용구 **따옴표**, 19.
- 해시태그: **13**.
- 배너(링크 버튼 이미지): 붙여넣기 때 배너 자리에 연결할 링크 주소를 함께 표시한다.
- 이미지: 썸네일·본문 사진·배너 모두 **가로 550px**(세로는 비율대로). build_assets.py가 자동 처리.
- **모바일 우선**: 독자 대부분이 휴대폰으로 본다. 한 줄은 20자 안팎에서 끊고, 표는 **3칸 이하**(넘치면 두 값을 한 칸에 "A / B"로). 긴 URL을 본문에 쓰지 않는다.
- 실존 인물 사진(썸네일 배경 등): 언론사 사진 금지. CC·공공누리 등 자유 이용 사진만 쓰고 본문 끝에 출처 한 줄.

## 3. 문체
- 모바일 기준 한 줄 25자 안팎에서 줄바꿈, 가운데 정렬, 2~3줄마다 빈 줄.
- 말투: “~해요/~거든요” 대화체 70% + 정보 문장 30%. 이모지는 섹션 표시용 ✅ ⚠️ 정도만 최소.
- 숫자·날짜·금액은 **굵게**, 가장 중요한 1~2곳만 형광(연두 #D9F99D) 강조.
- 1인칭 경험 한 줄 넣기(“저도 작년에 서류 하나 빠뜨려서 다시 냈어요” 같은 실제 경험이 있으면 대표님이 추가).

## 4. 뉴스 이슈형 글 (핫키워드가 정치·사회·연예인 경우)
- 이슈 자체를 해설하지 말고 **독자 돈 문제로 연결**한다. 블로그 정체성(청약·생활꿀팁·재테크·정책자금) 유지.
  - 엔비디아/젠슨황 쇼크 → “서학개미 해외주식 손실 났을 때 양도세 손익통산·연말 절세 체크리스트”
  - 이재용 주식 증여 → “부모님 집·주식 증여세 계산법, 10년 5천만원 공제”
  - 연예인 음주운전 → “음주운전 사고 시 보험 자기부담금·면허취소 기준 2026”
  - 노란우산 개인정보 유출 → “노란우산공제 가입자 확인할 것, 공제금·소득공제 혜택 정리”
- 정치 이슈는 특정 정당·인물 비판/지지 금지. 정책·제도 변화(세금, 지원금, 부동산 규제)만 사실 위주로.
- 사건·사고 피해자 실명, 범죄 단정 표현 금지.

## 4-1. 사진 원칙 (대표님 확정: 자극적이고 직관적으로)
- **썸네일 배경과 중간 사진은 주제가 한눈에 보이는 실제 사진이 1순위.** 무난한 노트북·꽃·풍경 같은 사진은 쓰지 않는다.
  - 인물 이슈 → 그 인물 실제 사진 (예: 젠슨 황, 머스크, 대통령)
  - 기업 이슈 → 본사 건물·로고 간판·제품 실제 사진
  - 우주·과학 → NASA 등 기관 공개 사진 (로켓 발사, 행성, 망원경 사진)
  - 정책·제도 → 정부 공식 사진, 해당 기관 건물
- 찾는 도구: `python3 realphoto.py "<영어 고유명사>" out/real/<key> 10` (위키미디어 커먼즈·플리커 자유 이용 사진·NASA). 검색어는 **고유명사**로("Elon Musk", "Samsung Electronics headquarters", "SpaceX Starship").
- 출처 표기만 하면 되는 사진만 쓴다: CC0·CC BY·CC BY-SA·공공누리·퍼블릭 도메인. 본문 끝에 `사진: 작가, 라이선스` 줄을 넣는다(candidates.json의 credit).
- **언론사·통신사 사진은 출처를 밝혀도 무단 사용 불가** → 절대 쓰지 않는다.
- 실제 사진을 못 찾은 칸만 photo.py(무료 스톡)로 채우되, 표정·상황이 강한 사진(충격, 머리 감싼 사람, 폭락 차트, 불타는 현장 등)을 고른다.
- 중간 사진 4장 중 **최소 2장은 주제와 직접 관련된 실제 사진**.
- **사건·범죄·부정적 이슈에는 그 사건과 무관한 사람의 얼굴 사진을 절대 쓰지 않는다**(명예훼손·초상권). 그럴 땐 제품·장소·사물 사진으로.

## 5. 썸네일 (thumb.js, 실사 사진 + 훅 문구)
- **AI 이미지 금지. 실사 사진만.** photo.py로 Pexels 또는 CC0 무료 스톡(StockSnap·WordPress 사진, 상업 이용 가능·출처 표기 불필요)에서 찾는다.
  - 사진 기준: 사람 표정이 보이는 사진 우선. 심각형(충격·걱정·머리 감싸기·휴대폰 보고 놀람) 또는 재밌는형(과장된 놀람·환호). 동아시아 인물 우선.
  - 검색어는 영어로: `shocked asian man phone`, `worried korean woman bills`, `stressed businessman laptop`, `surprised couple house` 등.
  - 뉴스·언론사 사진, 연예인·실존 인물 사진은 쓰지 않는다(저작권·초상권).
  - 후보 여러 장을 받아 직접 열어 보고 가장 표정이 강한 1장을 고른다.
- 1080×1080 카드형(대표님 확정 구도): 위 600px 관련 실사 사진 → 아래로 자연스럽게 어두워짐 → 어두운 패널.
  - 노란 주제 박스 `tag`: `분야 / 키워드` (예: `주식 / 엔비디아`)
  - 흰 글씨 3줄 `lines`: 1줄 상황, 2줄 훅(핵심 숫자·감정, `{ }`로 감싼 부분은 연두 강조), 3줄 결과·행동.
    예: `["엔비디아 폭락에", "{4,281억} 줍줍했다고?", "내년 세금 폭탄 주의"]`
  - 한 줄 12자 안팎. 길면 자동으로 작아지니 짧게 쓴다.
  - 사진을 못 구하면 테마색 배경 + `icon` 이모지로 대체된다.
- 본문 사진 2~3장도 photo.py로 고르고 `photos` 필드에 넣는다(본문 [사진] 자리에 순서대로 들어감).
