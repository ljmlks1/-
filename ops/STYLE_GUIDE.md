# 캐러셀 스타일 가이드 (이슈압축 · 유머밈어워드)

## 절대 규칙
- 템플릿 엔진은 `ops/templates/build.py` 하나만 쓴다. 레이아웃을 임의로 바꾸지 않는다.
- 모든 좌표는 원본 게시물(`ops/templates/ref/*.jpg`, 1024×1280)에서 측정한 값이다.
- 로고는 원본에서 잘라낸 `ops/templates/logos/*`만 쓴다. 새로 그리거나 바꾸지 않는다.
- 출력 크기는 1080×1350(4:5)으로 고정한다.
  - Instagram API는 4:5보다 세로로 긴 이미지(3:4 포함)를 거부한다.
  - 프로필 그리드에서는 4:5 이미지의 양옆이 조금 잘려 3:4로 보인다. 그래서 글자와 로고는 좌우 95px 안쪽에만 둔다.
- 마지막 장(엔드카드) 문구, 로고, 배치는 브랜드별로 고정이다. 둘째 줄 "○○ 좋아하는 친구에게 공유해요."만 주제에 맞게 바꾼다(유머 채널은 "함께 웃을 친구"로 고정).
- 엔드카드 배경은 표지 사진을 흑백·블러·어둡게 처리해서 쓴다.

## 장 구성 (6장 기본)
1. 표지
   - 위쪽은 사진. 아래쪽은 어두운 띠(#151716).
   - 띠 위에 노란 태그(#ffd83d) "분야 / 주제"를 둔다.
   - 제목은 3줄. 그중 1줄은 강조색으로 쓴다.
     - 이슈압축: 연두 #c2f471
     - 유머밈어워드: 주황 #fe7819
2. 본문 2~5장
   - 위쪽 사진은 매 장 다른 관련 사진을 쓴다.
   - 왼쪽 위에 캡션 칩을 단다(예: "자료사진 · …").
   - 제목은 가운데 정렬 2줄(강조 단어 1개), 본문은 4줄, 그 아래 다음 장으로 넘기게 하는 한 줄(→)을 넣는다.
3. 엔드카드(마지막 장)

하단 공통: 왼쪽 사진 크레딧 / 가운데 페이지 번호(01/06) / 오른쪽 작은 로고.

## 사진
- 매 장 주제와 관련 있으면서 서로 다른 사진을 쓴다(같은 사진 반복 금지).
- 출처 1순위: vidIQ `vidiq_find_broll` 결과의 Pexels 스틸 컷(무료, 크레딧 "Pexels / 작가명").
  - 받는 주소 형식: `https://images.pexels.com/videos/<id>/<file>.jpeg?...&h=1920&w=1080`
- 논문이나 공공 자료는 CC 라이선스일 때만 쓰고, 크레딧을 표기한다.
- 방송 화면 캡처는 저작권 위험이 있으므로 사용하지 않는다.
- 자료사진은 반드시 캡션 칩에 "자료사진"이라고 표시한다. 실제 인물이나 현장 사진인 것처럼 보이게 하지 않는다.

## 내용 (팩트 기본)
- 숫자, 날짜, 발언, 판결 하나하나를 직접 열람한 원문과 대조한다. 근거는 `ops/evidence/<ID>.md`에 남긴다.
- 출처가 하나뿐인 핵심 사실은 "○일 보도에 따르면"처럼 출처를 밝혀 쓴다. 매체끼리 엇갈리는 날짜는 월 단위까지만 쓴다.
- 본문은 풍성하게 쓴다. 장마다 새로운 정보를 하나씩 넣고, 같은 말을 반복하지 않는다.
- 캡션: 첫 줄은 후킹 문장으로 시작한다. 이모지 소제목 4단락 + 질문형 CTA로 구성하고, 해시태그는 5개 이하로 단다. 출처 URL은 넣지 않는다.

## 유머밈어워드 톤
- 공감형 연애·일상 밈, 번호를 매기는 유형 분류, 댓글로 번호를 남기게 하는 CTA를 쓴다.
- 직접 만든 채팅 화면은 사진 위에 반투명 카드로 올린다. 이때 사람 얼굴을 가리지 않게 배치한다(필요하면 왼쪽으로 옮긴다).

## 게시
- 같은 채널은 최소 4시간 간격을 둔다.
- 사용자가 컨펌한 정확한 버전만 게시한다.
