# 릴스 운영 규칙 (사용자 확정 2026-11-24)
- 릴스와 캐러셀은 완전히 다른 형식. 릴스에 캐러셀 슬라이드·카드·사진 슬라이드쇼 금지. **가운데는 실제 영상만.**
- 폼(ops/templates/reel.py): 1080x1920 검은 배경, 제목 2줄(1줄 흰색 / 2줄 주황, 크게), 영상 바로 위 약 1cm, 영상 아래 출처 한 줄. 원본 소리 그대로, 음성·음악·훅 대본 없음.
- **이모티콘 절대 금지** (제목·출처·캡션 모두). reel.py가 자동 제거.
- 훅 제목: 자극적으로 보고 싶게, 단 사실과 다르면 안 됨. 최근 이슈만.
- 영상 출처: 재사용 허락이 있는 영상만 — 퍼블릭 도메인(NASA·NOAA·USGS 등 미국 연방기관), ESA 등 CC 라이선스, 사용자가 허락받거나 직접 찍은 영상. 다른 채널·방송·유튜버 영상 재업로드 금지.
- 이슈압축: 하루 최소 3개, 속보·긴급속보는 쓸 수 있는 영상이 있으면 바로 제작·게시(사용자가 자동 게시 승인, 2026-11-24). 영상이 없으면 건너뛰고 기록.
- 사실은 기사 2곳 이상 확인(newsfind.py), ig-factcheck 판정 '발행 가능'만 게시.

## 유머밈 릴스: 사용 허락 채널 (사용자 확인 2026-11-24 — "3년간 해 왔고 승인 다 받음")
- 곽범, 허경환, 유재석, 신동엽, 이선민, 숏박스, 침착맨, 노빠꾸탁재훈, 짠한형 관련 채널의 **쇼츠**.
- 조건(사용자 전달): 영상은 편집하지 않고 그대로, 제목만 바꿔서, 아래에 출처(채널명) 표기.
- 이 목록에 없는 채널·방송사 공식 채널(MBC·SBS 등) 영상은 사용자가 따로 승인 확인해 줄 때까지 쓰지 않는다.
- 선정: 조회수 100만 이상, 최근 한 달 우선(없으면 레전드). 같은 영상 중복 게시 금지(ops/reels/ledger.json).
- 출처 줄은 "출처: 침착맨 유튜브"처럼 이름 + 유튜브만 쓴다. 링크 주소는 넣지 않는다 (사용자 지시 2026-11-25).

## 유머밈 릴스 자동 제작 절차 (2026-11-25 확정)
- 1순위: 놀면뭐하니(MBC 포함, 사용자 승인 범위라고 확인), 이선민, 곽범, 허경환. 그다음 침착맨·노빠꾸탁재훈·짠한형·유재석 고루. 숏박스는 비율 낮게.
- 유튜브/인스타 쇼츠·릴스 중 조회수 100만 이상만. 최근 한 달 우선, 없으면 레전드.
- 받기: yt-dlp는 이 서버에서 차단됨 → vidiq_video_upload에 유튜브 링크를 넣어 가져오고(vidiq_job_poll), 결과 videoUrl을 curl로 받는다.
- 편집: 원본의 위아래 제목 띠·채널 로고·채팅창·'풀버전' 안내는 전부 잘라내고 **실제 화면만** 남긴다(spec의 crop). 영상 안에 원래 박힌 자막은 화면 일부라 유지. 프레임을 직접 보고 crop 확인 필수.
- 제목: 상황을 보고 2줄(흰/주황). **짧고 센스 있게**(길게 설명하지 말 것, 줄당 2~8자 정도 펀치라인. 예: "단톡방 읽씹 / 실사판"). 채널명 절대 금지. 이모티콘 금지. (사용자 지시 2026-11-25)
- 출처 줄: "출처: ○○ 유튜브" 이름만. 링크 절대 금지.
- 예고·풀버전 유도형 쇼츠는 제외.
- 같은 계정 게시 2시간 간격, 캐러셀 게시 시각과 겹치지 않게.

## 게시 빈도 (사용자 지시 2026-11-25, 이전 지시 대체)
- 릴스는 계정마다 하루 3개만: 아침·점심·저녁.
  - 유머밈: KST 08:50 / 12:50 / 19:50
  - 이슈압축: KST 09:00 / 13:00 / 20:00 (속보는 해당 회차의 1개로 대체, 추가 게시 없음)

## 이슈압축 릴스 주제 (사용자 지시 2026-11-25: "과학쪽만 하는거 같은데 이슈가 안되는건 의미가 없어")
- 주제는 **지금 화제가 되는 이슈 우선**: collect.py HOT 상위, 네이버 랭킹 상위(경제·증시·부동산·사회·IT·엔비디아·정치 포함). 과학은 크게 화제일 때만.
- 영상 출처(재사용 가능한 것만):
  1. 공공누리 제1유형 정부·공공기관 영상(KTV·정책브리핑 등, 영상마다 표기 확인) — 출처 "영상: ○○(공공누리 제1유형)"
  2. 미국 연방기관(백악관·국방부·NASA·NOAA 등) 퍼블릭 도메인
  3. 이슈와 직접 관련된 CC 라이선스 자료영상(예: 증시 급락 → 증권 시세판 CC 영상), 화면 아래 '자료영상' 표기
- 방송사·언론사·유튜버 뉴스 영상은 사용하지 않음.

## 외국어 영상 한글 자막 (사용자 지시 2026-11-25: "한글자막 붙여줘야될것같은데 영어를 못알아들음")
- 말소리가 외국어인 영상은 반드시 한글 자막: spec "subs": [[시작초, 끝초, "자막(\n 줄바꿈)"]] (클립 기준 시각). reel.py가 영상 아래쪽 안에 반투명 검은 상자 + 흰 굵은 글씨로 넣는다.
- 번역은 유튜브 자막(vidiq_video_transcript) 기준으로 뜻만 정확히, 한 자막 2줄 이내.

## 릴스 진행 방식 (사용자 지시 2026-11-25, 이전 자동 제작·게시 대체)
- "릴스재료는 일단 만들기전에 나한테 내용하고 썸네일로 후보를 먼저 뽑아. 그럼 내가 만들어서 올리라고 미리 얘기해줄테니까"
- 자동 회차는 **후보만** 뽑는다: 후보마다 썸네일(영상 프레임 1장) + 한 줄 내용 + 제목안(2줄) + 원본 출처·조회수. 제작·게시 금지.
- 사용자가 고른 후보만 제작 → 최종본 보여주고 → 사용자가 말한 대로 게시.
- 영상 출처: 사용자가 "왠만한데는 영상 다 허가 받았다, 모든 권한은 나한테 있다"고 함(2026-11-25). 후보에는 원본 채널을 반드시 적어 사용자가 건별로 확인·선택하게 한다.
- 이슈압축 릴스는 가볍고 재미있는 내용도 괜찮음.
- 후보 고를 때: 말소리가 외국어인 영상은 되도록 빼고 한국어 영상 우선(사용자 2026-11-26, 여권 영상 '별로, 영어').

## 이슈압축 릴스 소재 (사용자 지시 2026-11-26, 최우선)
- "한국어로 된 것만, 뉴스든 뭐든 사건사고 오늘 핫한 거 위주로."
- 소재: 오늘(최근 24시간) 조회수가 빠르게 오르는 한국어 뉴스·사건사고 쇼츠(MBC·KBS·SBS·JTBC·YTN·연합뉴스TV·채널A·MBN·TV조선 등 공식 채널). 과학·우주 소재는 넣지 않음.
- 외국어 영상 제외. 화면만 봐도 무슨 일인지 바로 알 수 있는 것.
- 제작: 원본 위아래 제목 띠·로고 제거, 영상만 가져와 원본 제목과 거의 같은 직관적인 제목 2줄, 출처 "출처: ○○ 유튜브".
- 진행: 후보(썸네일+내용+제목안+조회수) 먼저 → 사용자가 고르면 제작 → 최종본 확인 → 같은 계정 3시간 간격 게시.

## 릴스 제목 기본값 (사용자 지시 2026-11-26)
- "릴스는 올릴 때 잘 모르겠으면 원본 제목과 거의 동일하게." 확신이 없으면 새로 지어내지 말고 원본 쇼츠 제목을 거의 그대로(두 줄로 나누기, 채널명·이모티콘·해시태그만 빼기) 쓴다. 두 계정 모두 적용.
- 검수 (사용자 지시 2026-11-26): "검수하게 최종본 올리기 전에 보여주고." 모든 릴스는 최종 mp4를 먼저 보여주고, 사용자가 확인·지시한 것만 게시.
