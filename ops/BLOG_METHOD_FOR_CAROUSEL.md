# 블로그 제작법 → 캐러셀 적용 (2026-11-24 사용자 지시)

사용자: "블로그에서 가져오는 스킬 전부 가져와서 캐러셀로 만들자. 내용이 블로그 게 더 잘 나오는 것 같아."
원본: 블로그최종 Artifact(https://claude.ai/artifact/9A9TkJDELb6dCCz8QrWCgm) published files → `ops/blogkit/` 에 그대로 복사
(RUNBOOK.md, STYLE.md, cold-verify.md, collect.py, newsfind.py, realphoto.py, photo.py, contact.py, thumb.js, btn.js, build_assets.py, helpers.py, example_drafts.py).
블로그 쪽 파일이 바뀌면 Artifact `read`로 다시 받아 덮어쓴다.

## 핵심: "블로그 글을 먼저 쓰고, 그걸 줄여서 캐러셀로"
블로그 초안이 없는 회차(랭킹 소재)도 바로 슬라이드를 쓰지 않는다.
1. 블로그 방식으로 전체 원고(1,800자 이상, STYLE.md 구조)를 먼저 `ops/items/<ID>/draft.md`에 쓴다.
2. 그 원고를 BLOG_TO_CAROUSEL.md 규칙대로 줄여 슬라이드로 만든다(내용 추가 금지, 줄이기만).

## 단계별 도구
| 단계 | 블로그 도구 | 캐러셀에서 |
|---|---|---|
| 소재 수집 | `python3 ops/blogkit/collect.py cand.json` | HOT 키워드(랭킹 가중) + 섹션 헤드라인을 같이 본다. count 높고 여러 섹션에 걸친 주제 우선. 연예 랭킹 API는 유머용으로 계속 병행 |
| 소재 선정 | RUNBOOK 3절 기준 | ① 랭킹 count 높고 섹션에도 등장 ② 독자 돈·생활과 직접 연결(이슈압축) ③ 2개 이상 출처 확보 ④ 최근 14일 미사용 |
| 사실 확인 | `python3 ops/blogkit/newsfind.py "검색어" 5` | 숫자·날짜·금액·전화번호는 2곳 이상 대조. 못 맞춘 건 쓰지 않는다 |
| 냉철 검증 | `ops/blogkit/cold-verify.md` (= ig-factcheck) | 판정(발행 가능/수정 후/보류)을 evidence 첫 줄에. 확신도 60% 미만 숫자는 삭제 |
| 사진 | `python3 ops/blogkit/realphoto.py "<영어 고유명사>" out 10` → `contact.py` | 위키미디어·플리커 자유 이용(CC0·CC BY·BY-SA)·NASA 사진을 먼저 찾고 contact.jpg를 직접 보고 고른다. 출처 한 줄 표기 |

## 표지 = 블로그 제목·썸네일 공식
- 제목 공식: `[훅(감정)] + [핵심 키워드] + [숫자] + [행동 약속]`, 핵심 키워드는 앞쪽에.
  훅: 경고형(또 터졌다? / 지금 당장 확인) · 반문형(이게 실화? / 나도 해당될까?) · 손해 회피형(세금 폭탄 맞기 전에) · 숫자 약속형(5가지 총정리)
- 확실하지 않으면 물음표. 사실과 다른 과장 금지. 인물 비하·범죄 단정 금지.
- 노란 태그 `분야 / 키워드`, 3줄(상황 → 훅 숫자 → 결과·행동), 강조는 `<a>`.

## 슬라이드 순서 = 블로그 본문 순서
표지 → ① 인용구 훅(결론 숫자 + 날짜·대상, 첫 장에 금액·날짜·대상이 다 나오게) → ② 핵심 요약(누가/얼마/언제, 2열 정리) →
③ 대상·조건 → ④ 내용(숫자) → ⑤ 방법·체크리스트(단계) → ⑥ 주의할 점·FAQ → 엔딩(문의처·기준일·면책 한 줄).
과학·IT·연예는 블로그 비축 글 구조(①~⑤ 번호 소제목 + Q&A)를 그대로 따른다.

## 문체
해요체 70% + 정보 문장 30%, 숫자는 강조, 한 줄 20~25자(문단열 규칙과 동일), 이모지는 ✅ ⚠️ 정도.
이슈압축의 정치·사회·연예 이슈는 블로그 STYLE 4절처럼 **독자 돈·제도 문제로 연결**한다.

## 사진 원칙 차이 (사용자 결정 필요 — 결정 전까지 기존 방식 유지)
블로그 STYLE: "언론사·통신사 사진은 출처를 밝혀도 무단 사용 불가 → 절대 쓰지 않는다."
캐러셀 현행: 보도사진에 출처 표기해 사용(방송 캡처 포함).
→ 자유 이용 사진(realphoto)을 먼저 찾고, 못 찾을 때만 기존 방식. 사용자가 블로그 원칙으로 통일하라고 하면 보도사진 사용을 중단한다.
