# ig-factcheck · 냉철한 검증 6단계

캐러셀(표지·본문·캡션)을 만든 뒤, 사용자에게 전달하거나 게시하기 **직전**에 이 6단계를 순서대로 돌린다.
결과는 ops/evidence/<ID>.md 끝에 `## 검증` 섹션으로 남기고, 사용자에게는 "고친 것/뺀 것/남은 위험"만 짧게 보고한다.

## 원칙
- 내가 만든 초안을 변호하지 않는다. 사용자의 요청 문구라도 사실과 다르면 그대로 쓰지 않는다(예: "월급 600억" → 주식 평가액 단순 평균).
- 빈말 칭찬·위로 없이 구멍부터 말한다.
- 확인 못 한 것은 "확인 안 됨"으로 비워 둔다. 지어내서 채우지 않는다.

## 1. 예스맨 모드 끄기
> "내 주장을 정당화하지도 말고, 내 기분도 맞추지 마. 빈말 칭찬이나 위로는 첫 줄부터 전부 생략해. 내 [기획안/원고]에서 논리가 빈약하거나 현실성 없는 구멍만 직설적으로 짚어내."

적용: 표지 제목·각 장 제목이 본문 사실보다 과장됐는지, 인과관계를 단정했는지(연구 결과 ↔ 인과 증명), 물음표 뒤에 숨긴 허위 단정이 없는지 본다.

## 2. 반대편 심사위원
> "넌 지금 내 [상품/콘텐츠]를 무조건 탈락시키려는 까다로운 [결제 고객/투자자]야. 장점은 단 한 줄도 적지 마. 사람들이 안 사고 그냥 이탈할 치명적 이유 3가지만 냉정하게 공격해."

적용: 까다로운 팩트체커·당사자(출연자, 기업, 유족)·플랫폼 심사 입장에서 "이 게시물을 내려야 할 치명적 이유 3가지"를 적는다. 명예훼손, 초상권·저작권, 사망·자살 보도 기준, 투자 권유 오해, 정치 편향, 이해상충(앤트로픽 관련)을 반드시 포함해 검사한다.

## 3. 숫자 조건 못 박기
> "답하기 전에 내 현실 조건부터 고정할게. 목표 결과 / 가진 자원 / 실패한 시도. 이 조건 안에서만 통할 현실 해법을 내봐."

적용: 모든 수치에 **기준 시각·출처·단위**를 붙인다.
- 주가·환율·순위·조회수: "OO일 OO시(현지/한국) 기준" 명시, 게시 직전 재확인
- 금액: 원/달러 환산 환율과 날짜, 평균인지 중앙값인지 개인값인지
- 집계: "오후 2시 기준 59건" vs "오후 3시 기준 50건"처럼 매체마다 다르면 시각을 붙여 하나만 쓴다
- 계정 조건: @issue.ap(과학·IT·사회·경제, 정치 제외) / @legendhumormeme(연예·유머)

## 4. 실패 본 실무자 (이 계정에서 실제로 틀렸던 함정)
> "'전문가처럼' 뻔한 교과서 조언은 금지야. 현장에서 망해가는 계정을 수백 개 뜯어고친 실무자 시선으로 봐줘. 초보자가 제일 많이 착각하는 함정부터 내 초안에서 골라내."

체크리스트:
- [ ] 동명이인: 이름만 같은 다른 사람 사진(예: 개그우먼 김지민 ↔ 하트시그널 김지민)
- [ ] 사진 = 해당 장 내용인가? 한국 주제에 외국 스톡 금지, 단지·인물·장면 그대로
- [ ] 방송 캐러셀: 실제 방송 장면 + 그 장면의 실제 대사(따옴표). 자막 문구와 인용 문구 일치. "웃음을 자아냈다" 식 요약 금지
- [ ] 지난 이슈(수능 전날, 상장 전 공모가 등)를 현재형으로 쓰지 않았나
- [ ] 소식통·추정치(힐 추정, 로이터 추산)를 확정처럼 쓰지 않았나
- [ ] 평균 ≠ 개인, 공모가 ≠ 현재가, 주식 평가액 ≠ 월급
- [ ] 블로그 원문 표·날짜도 원출처와 대조(예: 김범수 기소 2023.11 ✗ → 2024.8)
- [ ] 사진 출처 표기(자료사진·크레딧), 다른 계정 완성 게시물 복제 금지
- [ ] 캡션: 본문 + 해시태그 최대 5개, URL 금지
- [ ] 사망·자살: 방법·유서 언급 금지, 의혹은 "확인 안 됨", 상담전화 109 / 1577-0199

## 5. 확신 점수 매기기
> "결론부터 단정 지어 말하지 마. 주장마다 [확인된 팩트]와 [네 추측]을 칼같이 분리해서 적어. 각 판단 옆에 확신도를 [0~100%] 숫자로 매기고, 근거가 약한 곳은 솔직히 비워둬."

적용: 캐러셀의 모든 사실 문장을 표로 만든다.

| 장 | 문장 | 구분(팩트/추측) | 출처 | 확신도 |
|---|---|---|---|---|

- 90~100: 원출처(공식 발표·판결문·방송 원본) 또는 독립 2곳 이상 일치 → 그대로
- 70~89: 1곳 보도 → "~라고 보도됐어요/~래요"로 출처 표현
- 70 미만: 빼거나 "확인 안 됨"으로 표시. 표지·제목에는 절대 쓰지 않는다

## 6. 망한 뒤 역추적
> "이 계획이 [6개월 뒤 완전히 망했다]고 가정해 봐. 내가 당연하다고 착각했던 전제 중 무엇이 깨져서 망했는지 찾아내. ① 가장 먼저 터질 약한 고리 1개 ② 오늘 당장 돈 안 쓰고 확인할 검증법 1개"

적용: "이 게시물이 올라간 뒤 정정·삭제 요청을 받았다"고 가정하고
① 가장 먼저 문제 될 문장/사진 1개
② 지금 바로 할 수 있는 확인 1개(원문 기사 재확인, 영상 자막 대조, 주가 재조회 등)
를 적고, ②를 실제로 수행한 뒤 결과를 반영한다.

## 출력 형식 (evidence 파일 끝)
```
## 검증 (ig-factcheck, YYYY-MM-DD HH:MM KST)
1 예스맨: …
2 심사위원 치명적 이유 3: …
3 숫자 조건: 기준시각/출처/단위 …
4 함정 체크: 통과 n / 수정 n (무엇을)
5 확신 점수표: (표) — 70 미만 n개 삭제/완화
6 역추적: 약한 고리 … / 오늘 확인 … → 결과 …
판정: 전달 가능 / 수정 후 전달 / 만들지 않음(사유)
```
